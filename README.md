# Learning Lang Pro

A multilingual language learning app built with Flutter + FastAPI + Supabase.

## Structure

```
learning-pro/
├── app/          # Flutter app (Android, iOS, Web)
└── backend/      # FastAPI backend on Render
```

## Setup

See [app/README.md](app/README.md) and [backend/README.md](backend/README.md) for setup instructions.

## Tech Stack

- **Frontend**: Flutter (Dart)
- **Backend**: FastAPI (Python) on Render
- **Database**: Supabase (PostgreSQL)
- **AI**: OpenAI GPT-4o + GPT-4o-mini
- **Images**: Midjourney (flashcards)
- **Storage**: Supabase Storage
